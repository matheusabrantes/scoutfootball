# ScoutFootball Data Contract

This contract defines the API and data shapes used for mock frontend/backend development before a real data provider is connected. The contract should stay provider-neutral. Provider-specific fields belong in ingestion adapters and source metadata, not in frontend-facing responses.

## Conventions

- IDs are stable strings generated by ScoutFootball unless a future provider id is explicitly namespaced.
- Dates use ISO `YYYY-MM-DD`.
- Timestamps use ISO 8601 UTC strings.
- Missing numeric values are `null`.
- Metric availability is one of `available`, `approximated`, or `unavailable`.
- Percentiles are `0` to `100`, where higher is better unless a metric explicitly sets `higherIsBetter: false`.
- MVP responses cover current season and last completed season only.

## Python / Pydantic Models

These examples mirror the TypeScript contract and should guide backend schemas.

```py
from datetime import date, datetime
from typing import Literal

from pydantic import BaseModel, Field


PositionGroup = Literal[
    "goalkeepers",
    "centrebacks",
    "fullbacks",
    "midfielders",
    "attackers",
]

MetricAvailability = Literal["available", "approximated", "unavailable"]
SeasonStatus = Literal["current", "last_completed"]
SortDirection = Literal["asc", "desc"]


class League(BaseModel):
    id: str
    name: str
    country: str
    region: Literal["Europe", "South America"]
    slug: str
    is_supported: bool
    provider_league_ids: dict[str, str | int] = Field(default_factory=dict)


class Season(BaseModel):
    id: str
    name: str
    status: SeasonStatus
    start_date: date
    end_date: date
    is_current: bool


class Club(BaseModel):
    id: str
    name: str
    slug: str
    league_id: str
    season_id: str
    country: str
    provider_club_ids: dict[str, str | int] = Field(default_factory=dict)


class Player(BaseModel):
    id: str
    name: str
    slug: str
    date_of_birth: date | None = None
    age: int | None = None
    nationality: str | None = None
    primary_position: str | None = None
    position_group: PositionGroup
    provider_player_ids: dict[str, str | int] = Field(default_factory=dict)


class PlayerSeasonStats(BaseModel):
    id: str
    player_id: str
    season_id: str
    league_id: str
    club_id: str
    position_group: PositionGroup
    minutes_played: int
    appearances: int | None = None
    starts: int | None = None
    source_id: str
    ingestion_run_id: str
    last_updated_at: datetime


class Metric(BaseModel):
    key: str
    label: str
    short_label: str
    description: str
    unit: Literal["count", "per90", "percent", "score"]
    position_groups: list[PositionGroup]
    higher_is_better: bool = True
    decimal_places: int = 2
    availability: MetricAvailability
    approximation_note: str | None = None
    source_metric_keys: list[str] = Field(default_factory=list)


class PlayerMetricValue(BaseModel):
    player_id: str
    player_season_stats_id: str
    metric_key: str
    raw_value: float | None = None
    display_value: str
    percentile: float | None = Field(default=None, ge=0, le=100)
    rank: int | None = None
    peer_count: int
    availability: MetricAvailability
    calculation_version: str
    source_id: str
    last_updated_at: datetime
```

## Response Models

```py
class RankingFilters(BaseModel):
    season_id: str
    league_id: str | None = None
    position_group: PositionGroup
    metric_key: str
    minutes_min: int
    sort_by: Literal["raw_value", "percentile"]
    direction: SortDirection


class RankingPlayerRow(BaseModel):
    player: Player
    season_stats: PlayerSeasonStats
    league: League
    club: Club
    selected_metric: PlayerMetricValue
    summary_metrics: list[PlayerMetricValue]


class RankingResponse(BaseModel):
    filters: RankingFilters
    metric: Metric
    rows: list[RankingPlayerRow]
    total: int
    limit: int
    offset: int


class PlayerProfileContext(BaseModel):
    season: Season
    league: League
    club: Club
    season_stats: PlayerSeasonStats


class SourceSummary(BaseModel):
    source_id: str
    source_name: str
    last_updated_at: datetime
    unsupported_metric_count: int
    approximated_metric_count: int


class PlayerProfileResponse(BaseModel):
    player: Player
    current_context: PlayerProfileContext
    metrics: list[PlayerMetricValue]
    metric_definitions: list[Metric]
    source_summary: SourceSummary


class ComparisonPlayer(BaseModel):
    player: Player
    season_stats: PlayerSeasonStats
    league: League
    club: Club
    metrics: dict[str, PlayerMetricValue]


class PlayerComparisonResponse(BaseModel):
    season: Season
    position_group: PositionGroup | None = None
    players: list[ComparisonPlayer]
    metrics: list[Metric]
    warnings: list[str] = Field(default_factory=list)
```

## Mock Development Rules

- Mock data should include at least one league from Europe and one from South America.
- Mock data should include all five position groups.
- Mock metrics should include available, approximated, and unavailable examples.
- Mock comparison responses should include 2 to 5 players.
- Mock ranking responses should include enough rows to test sorting, filtering, pagination, and empty states.
- Mock values must not be copied from DataMB or any proprietary source.
